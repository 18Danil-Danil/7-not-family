# 7 нот, одна семья

Сайт семейного музыкального фестиваля Ряжской детской музыкальной школы.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Готовая статическая версия находится в `dist`.

## Публикация на Cloudflare Pages

- Подключить GitHub-репозиторий.
- Framework preset: **Vite**.
- Build command: `npm run build`.
- Build output directory: `dist`.

## Обновление материалов

- Программа мероприятий: `src/data.ts`, массив `events`.
- Новости: `src/data.ts`, массив `news`.
- Фотографии: заменять URL в `src/App.tsx` или добавить файлы в `public/images/`.

## Перед публичным запуском

Проверить и заполнить точные контакты школы, официальные ссылки, утверждённые даты мероприятий, сведения о поддержке ПФКИ и согласия на публикацию фотографий участников.
